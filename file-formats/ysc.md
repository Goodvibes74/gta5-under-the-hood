# YSC compiled scripts

The game's scripts, compiled to bytecode for its script VM. Build 3725 has 1,143 of them in `update\update2.rpf` (plus Pilot School copies in `x64w.rpf`).

The header layout (64-bit PC), how strings are stored, and how to dump them: [research tools](/docs/00-getting-started/research-tools.md). How the VM runs them (threads, stacks, waits, events): [script VM](/scripting/script-vm.md). Reading them decompiled: [decompiled scripts](/docs/00-getting-started/decompiled-scripts.md). Every script, grouped: [story catalog](/docs/gameplay/missions/story-script-catalog.md) and [Online catalog](/docs/online/02-script-catalog.md).
