# Native namespace map

Every native namespace the game scripts use: how big it is, how many scripts call it, what it is for, and which roadmap topic explains it, so no engine API family is left without an owner. Roadmap topic **R0.8** in the [roadmap](/ROADMAP.md). Builds on [native usage](/scripting/native-usage.md) (R0.3) and its [per-namespace index](/scripting/native-usage-index.md); background on what natives are is in [natives](/scripting/natives.md).

**How it was made.** Namespace sizes, used natives and call counts come from the [native usage index](/scripting/native-usage-index.md) (generated by [`tools/native-usage.ps1`](/tools/README.md) from NativeDB's names and the decompile at commit `6c18d3e8b`, build 1.0.3725.0 Legacy). The number of scripts that call at least one native of a namespace was counted with one `git grep -o` over every decompiled script for `NS::NAME(` call sites, one count per script and namespace. The decompiler uses older names for eight namespaces than NativeDB; they were matched as `CAM` = `CAMERA`, `PATHFIND` = `PATH`, `SYSTEM` = `BUILTIN`, `APP` = `APPS`, `FILES` = `EXTRAMETADATA`, `MOBILE` = `GTA`, `LOADINGSCREEN` = `LOBBY`, `ITEMSET` = `ITEMSETS`. Numbers are **Verified**. The "What it covers" and "Topic" columns are this page's own grouping (editorial, from the native names and the scripts that use them).

## Short version

- **45 named namespaces** plus 2 natives NativeDB has no entry for. The scripts import 6,575 different natives and make 12.3 million native calls.
- **Five namespaces carry over half the calls:** `PLAYER` (2.72 million, mostly `PLAYER_PED_ID` and `PLAYER_ID`), `MISC` (1.39 million, mostly bit operations), `ENTITY` (1.34 million), `EXTRAMETADATA` (1.20 million, shop item lookups) and `PED` (1.12 million).
- **The biggest by size** are `NETWORK` (882 natives), `VEHICLE` (779), `PED` (617), `HUD` (522) and `GRAPHICS` (409). Every `VEHICLE` native is used by some script, and all but two of `PED`'s.
- **Almost every script uses the core:** `SCRIPT` (1,000 scripts), `BUILTIN` (998), `PLAYER` (990), `MISC` (988), `ENTITY` (960), `NETWORK` (941).
- **The least used:** `APPS` (2 scripts), `SAVEMIGRATION` (3), `ITEMSETS` (6), `REPLAY` (12), `SECURITY` (20).
- **Natives no script uses** are concentrated in `MONEY` (54 of 359), `NETWORK` (25), `SOCIALCLUB` (17) and `SCRIPT` (10).
- **Coverage:** 17 of the 46 rows point at at least one finished guide; the other 29 depend only on open topics. The big uncovered families are `PAD` (input, R6.4), `HUD` (R8.4), `TASK` (AI tasks, R17.1), `CAMERA` (R13.5), `AUDIO` (R9.x) and `EXTRAMETADATA` (shop items, R6.3).

## Reading the map

- **`MISC` is a junk drawer.** Its 334 natives range from `SET_BIT` and string checks (used everywhere) to weather (`SET_WEATHER_TYPE_*`), cheats, area checks, the game timer and save flags. Its natives belong to many topics; look a native up in the [MISC usage page](/scripting/native-usage/MISC.md) to see which scripts use it.
- **`EXTRAMETADATA` is huge in calls but small in natives.** 49 natives make 1.2 million calls because shop scripts and Online look up every clothing and tattoo item through it (`IS_CONTENT_ITEM_LOCKED` in 630 scripts).
- **`GRAPHICS` covers four topics.** Drawing sprites and text on screen, scaleform movies (R8.2), timecycles and post effects (R13.2), and particles and decals (R13.3).
- **Script counts are inflated by shared code.** Rockstar compiles helper code into most scripts, so a native can appear in hundreds of scripts that never reach it (for example the `CLOCK` date helpers in 520 or so scripts). For "who really uses this", read the busiest scripts on the namespace's usage page.

## What this means for modders

- **Find the natives for a job by namespace,** then use the usage page to see how Rockstar calls them: input is `PAD`, screen text and blips are `HUD`, AI is `TASK` and `PED`, cameras are `CAMERA`, sounds are `AUDIO`, loading is `STREAMING`.
- **Avoid the Online-only families in story mods:** `NETWORK`, `NETSHOPPING`, `MONEY`'s `NETWORK_*` natives, `SOCIALCLUB`, `LOBBY`. They expect a session or the server, and calling them in GTA Online risks a ban.
- **Names in other tools differ.** ScriptHookV's headers and older decompiles use `CAM`, `PATHFIND`, `SYSTEM`, `APP`, `FILES`, `MOBILE`, `LOADINGSCREEN` and `ITEMSET` for the namespaces NativeDB calls `CAMERA`, `PATH`, `BUILTIN`, `APPS`, `EXTRAMETADATA`, `GTA`, `LOBBY` and `ITEMSETS`. The hash is what counts.
