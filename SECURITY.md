# Security

This repository is **Markdown only**: it must never contain executables, binaries, archives or downloaded files. The few plain-text script sources (`tools/*.ps1`, `examples/*.cs`) are reviewed by the maintainer and must not download or run anything.

**If you find anything else** (a binary, an archive, an encoded or download-and-run script, or a link to a re-uploaded tool or a suspicious download), please don't run it. Open an issue titled `Security: <file or link>`, or use GitHub's "Report a vulnerability" button on the Security tab for anything sensitive. It will be removed and the history checked.

Only download tools from their official pages (linked in [setup](/docs/00-getting-started/setup.md) and the [toolbox](/docs/00-getting-started/toolbox.md)).
